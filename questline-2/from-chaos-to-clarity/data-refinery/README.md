# Data Refinery – Students Performance Dataset

## Objective

Clean the Students Performance Dataset using Python.

## Cleaning Steps

1. Loaded the dataset using Pandas.
2. Checked for missing values. There were no missing values.
3. Removed duplicate rows using `drop_duplicates()`.
4. Checked again for missing values and duplicates.
5. Saved the cleaned dataset as `cleaned_students_performance.csv`.

## Result

- Missing values: 0
- Duplicate rows: 0
- Cleaned file: `cleaned_students_performance.csv`
