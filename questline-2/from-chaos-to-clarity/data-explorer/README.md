# Student Performance Data Explorer

## Objective

Performed an initial exploration of the Students Performance Dataset using Python and Pandas.

## Dataset

Students Performance Dataset from Kaggle.

## Analysis Performed

- Loaded the dataset using Pandas
- Checked the dataset shape
- Listed all columns
- Inspected the data types
- Checked for missing values
- Generated summary statistics for numerical features

## Observations

The dataset contains 1000 rows and 8 columns.

The dataset contains both categorical and numerical features.

There are no missing values in any of the columns.

The numerical features are:
- Math score
- Reading score
- Writing score

The average scores are approximately:
- Math: 66.09
- Reading: 69.17
- Writing: 68.05

The maximum score for all three subjects is 100.
